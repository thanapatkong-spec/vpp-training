# ระบบสมาชิก (ระยะ A): สมัคร + ดาวน์โหลดใบประกาศนียบัตร

ผู้ที่เคยเรียนสมัครสมาชิก (อีเมล หรือ Google) → ยื่นคำขอรับใบประกาศ → แอดมินตรวจและอนุมัติพร้อมแนบ PDF → ผู้เรียนดาวน์โหลดใบจากหน้า **บัญชีของฉัน** (`/account`)

> ระบบนี้ต้องมีเซิร์ฟเวอร์และฐานข้อมูล **ใช้บน GitHub Pages ไม่ได้** ต้อง deploy ที่ Vercel + Neon ตามด้านล่าง
> บน GitHub Pages ลิงก์ "เข้าสู่ระบบ" จะถูกซ่อนไว้ (ปิดด้วย `NUXT_PUBLIC_MEMBERS_ENABLED=false`)

## 1) Deploy ที่ Vercel
1. vercel.com → Add New → Project → Import `vpp-training` (Framework: Nuxt, **ไม่ต้องแก้ Build Command**)
   - ถ้าไม่เห็น repo ให้ไปที่ GitHub → Settings → Applications → Vercel → Configure → Repository access แล้วเพิ่ม `vpp-training`
2. ใส่ Environment Variables ก่อนกด Deploy

| ตัวแปร | ค่า |
|---|---|
| `BETTER_AUTH_SECRET` | สตริงสุ่มยาว ≥ 32 ตัวอักษร (เก็บเป็นความลับ) |
| `BETTER_AUTH_URL` | URL จริงของเว็บ เช่น `https://vpp-training.vercel.app` |
| `ADMIN_EMAILS` | อีเมลแอดมิน (คั่นด้วยจุลภาค) |
| `ADMIN_KEY` | (ไม่บังคับ) รหัสแอดมินพิเศษ ≥12 ตัวอักษร ใช้เข้า `/manage` โดยไม่ต้องยืนยันอีเมล (อีเมลต้องอยู่ใน `ADMIN_EMAILS` ด้วย) |
| `NUXT_PUBLIC_MEMBERS_ENABLED` | `true` |
| `SMTP_USER`, `SMTP_PASS` (หรือ `RESEND_API_KEY`, `MAIL_FROM`) | ดูข้อ 4 |
| `NUXT_PUBLIC_GOOGLE_LOGIN`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | ดูข้อ 3 |

## 2) ฐานข้อมูล (Neon ผ่าน Vercel — ไม่ต้องรันคำสั่งเอง)
1. ในโปรเจกต์บน Vercel → แท็บ **Storage** → Create Database → **Neon** (Marketplace) → Connect to project
   - Vercel จะเพิ่ม `DATABASE_URL` ให้อัตโนมัติ (ระบบอ่านตัวแปรนี้เอง)
2. กด **Redeploy** ตอน build สคริปต์ `scripts/vercel-build.mjs` จะ **สร้าง/อัปเดตตารางให้อัตโนมัติ** (`drizzle-kit push`) ถ้าไม่มี `DATABASE_URL` จะข้ามขั้นนี้
- ใช้ Neon นอก Vercel ก็ได้: ตั้ง `DATABASE_URL` (หรือ `NUXT_DATABASE_URL`) เป็น connection string ของ Neon
- สร้างตารางเองจากเครื่อง: `DATABASE_URL="<connection string>" npm run db:push`
- ถ้าแก้ `server/db/schema.ts` แล้วการเปลี่ยนอาจทำให้ข้อมูลหาย `drizzle-kit push` จะหยุดและ build ล้ม ให้ตรวจก่อนแล้วค่อยดำเนินการ

## 3) ล็อกอินด้วย Google
1. console.cloud.google.com → APIs & Services → Credentials → Create OAuth client ID (Web application)
2. Authorized redirect URI: `https://<โดเมนของเว็บ>/api/auth/callback/google` (ใส่ `http://localhost:3000/api/auth/callback/google` ด้วยถ้าจะลองในเครื่อง)
3. ใส่ Client ID/Secret ใน Vercel แล้วตั้ง `NUXT_PUBLIC_GOOGLE_LOGIN=true`

## 4) อีเมลจากระบบ (Gmail หรือ Resend)
**แบบ ก: Gmail / Google Workspace (ง่ายสุด ไม่ต้องแก้ DNS)**
1. ล็อกอินบัญชีผู้ส่ง (เช่น info@vetvpp.com) → myaccount.google.com → ความปลอดภัย → เปิด **การยืนยันแบบ 2 ขั้นตอน**
2. myaccount.google.com/apppasswords → สร้างรหัสผ่านสำหรับแอป ชื่อ "VPP website" → ได้รหัส 16 ตัว
3. ตั้ง `SMTP_USER` = อีเมลนั้น และ `SMTP_PASS` = รหัส 16 ตัว (ผู้ส่งจะเป็น "VPP <อีเมลนั้น>")
4. โควตา: Gmail ส่วนตัว ~500 ฉบับ/วัน, Google Workspace ~2,000 ฉบับ/วัน

**แบบ ข: Resend** — resend.com → ยืนยันโดเมนผู้ส่ง แล้วตั้ง `RESEND_API_KEY` และ `MAIL_FROM` (เช่น `"VPP <no-reply@vetvpp.com>"`)

ถ้าตั้งทั้งสองแบบ ระบบใช้ Gmail ก่อน / ไม่ตั้งเลย ระบบไม่ส่งอีเมล (พิมพ์ลิงก์ลง log) เหมาะกับการลองเท่านั้น
ไม่บังคับยืนยันอีเมลก่อนล็อกอิน เว้นแต่ตั้ง `REQUIRE_EMAIL_VERIFICATION=true`

## แอดมิน
- อีเมลใน `ADMIN_EMAILS` ที่ **ยืนยันอีเมลแล้ว** (หรือเข้าด้วย Google) จะเห็นปุ่ม "จัดการคำขอ (แอดมิน)" ในหน้าบัญชี → `/manage`
- ตรวจคำขอ เทียบกับทะเบียนผู้เรียนของคุณ แล้วเลือกไฟล์ PDF (ไม่เกิน 4MB) กด "อนุมัติและส่งใบประกาศ" ใบจะขึ้นในบัญชีของผู้ยื่นทันที หรือกด "ไม่อนุมัติ" พร้อมหมายเหตุ
- ใบประกาศดาวน์โหลดได้เฉพาะเจ้าของบัญชีและแอดมิน

## ข้อมูลส่วนบุคคล (PDPA)
- ระบบเก็บ ชื่อ อีเมล ข้อมูลคำขอ และไฟล์ใบประกาศ เก็บใน Postgres (ไฟล์ PDF เก็บเป็น bytea ในตาราง `cert_files` ไม่อยู่ใน repo)
- หน้า `/privacy` เป็น **ข้อความร่าง** ควรให้ผู้เชี่ยวชาญตรวจก่อนเปิดใช้ แก้ได้ที่ `/admin/` → หน้าเนื้อหา → นโยบายความเป็นส่วนตัว
- ถ้าจำนวนไฟล์ใหญ่ขึ้น ย้ายไปเก็บที่ Cloudflare R2/S3 ได้ โดยเปลี่ยนเฉพาะที่ `approve.post.ts` และ `file.get.ts`

## ที่ยังไม่มี (ระยะถัดไป)
- ระยะ B: แต้มสะสมและตัวติดตามอายุบัตร (ต้องมีเกณฑ์แต้มและกิจกรรมที่ได้แต้ม)
- ระยะ C: เรียนจากวิดีโอ + ข้อสอบ ที่ให้แต้มอัตโนมัติ

## นำเข้าสมาชิกจากรายชื่อ (Excel)
แอดมินเข้า `/manage` → ส่วน "นำเข้าสมาชิกจากรายชื่อ" เลือกไฟล์ .xlsx ที่มีชีต `VPP 1`, `VPP 2`, ... (คอลัมน์ ชื่อ-สกุล / เบอร์โทรศัพท์ / อีเมล) → "ตรวจสอบก่อน" → "ยืนยันนำเข้า"
- ไฟล์ถูกอ่านในเบราว์เซอร์ ส่งเฉพาะชื่อ/อีเมล/เบอร์/รุ่นไปที่ฐานข้อมูล ไม่เก็บไฟล์ และ **ห้ามนำไฟล์รายชื่อใส่ใน GitHub**
- ข้ามแถวที่ไม่มีอีเมล อีเมลไม่ถูกต้อง หรือมีบัญชีอยู่แล้ว
- บัญชีที่นำเข้ายังไม่มีรหัสผ่าน: เข้าสู่ระบบด้วย Google (อีเมลเดียวกัน) หรือใช้ "ลืมรหัสผ่าน" (ต้องตั้ง Resend)

## แก้เนื้อหาเว็บในหน้าแอดมิน (มีผลทันที)
หน้าแอดมิน > **เนื้อหาเว็บ**: รุ่นที่เปิดรับสมัคร, บทความ, คำถามที่พบบ่อย, เอกสารแนบ, อัลบั้มรูป, หน้าเนื้อหา และ **ตั้งค่าเว็บไซต์**
- ทั้งหมดเก็บในฐานข้อมูล (ตาราง `content_items`, `cohorts`) — บันทึกแล้วแสดงบนเว็บทันที ไม่ต้องรอ build
- ไฟล์ใน `content/` เป็นข้อมูลตั้งต้น: ระบบคัดลอกเข้าฐานข้อมูลครั้งแรกของแต่ละหมวด หลังจากนั้นแก้ในหน้าแอดมินเท่านั้น (แก้ไฟล์ใน content/ จะไม่มีผล)
- **ตั้งค่าเว็บไซต์**: ข้อความหน้าแรก, ชื่อแพ็กเกจ, ช่องทางติดต่อ/ท้ายเว็บ, บัญชีรับเงิน (QR), ตัวเลือกคำนำหน้า/วุฒิการศึกษาในฟอร์มสมัคร — ช่องว่าง = ใช้ค่าเดิม
- รูป/ไฟล์ที่อัปโหลด: ถ้าเชื่อม Vercel Blob (`BLOB_READ_WRITE_TOKEN`) เก็บที่ Blob ไม่งั้นเก็บในฐานข้อมูล (ตาราง `media`, ไม่เกิน 3MB/ไฟล์) · ไฟล์เดิมใน `public/uploads/` ยังใช้ได้
- ไม่ต้องใช้ `GITHUB_TOKEN` แล้ว · เว็บบน GitHub Pages เลิกใช้ (เหลือหน้าส่งต่อไป Vercel)

## ให้สมาชิกที่แอดมินสร้างไว้ มาเป็นเจ้าของบัญชี
1. แอดมินเข้า `/manage` → สมาชิกและใบประกาศ → กด "จัดการ" ที่แถวสมาชิก → **สร้างลิงก์เปิดใช้งาน** (อายุ 14 วัน ใช้ได้ครั้งเดียว) → คัดลอกส่งให้เจ้าของทาง LINE/อีเมล
   (ส่งทั้งรุ่นพร้อมกัน: ปุ่ม "ดาวน์โหลดลิงก์เปิดใช้งาน (CSV)" ข้างช่องค้นหา เลือกรุ่นก่อนได้ ลิงก์เก่าที่ยังไม่ได้ใช้จะถูกยกเลิก)
2. เจ้าของเปิดลิงก์ → ตั้งรหัสผ่าน (ถ้าแอดมินยังไม่มีอีเมลของเขา ให้กรอกอีเมลด้วย) + ยอมรับนโยบายความเป็นส่วนตัว → เข้าสู่ระบบด้วยอีเมลและรหัสผ่านได้ทันที
3. ทางอื่น: เข้าด้วย Google (อีเมลเดียวกับที่แอดมินบันทึกไว้) จะผูกกับบัญชีที่สร้างไว้ให้อัตโนมัติ
- สมาชิกที่ไม่มีอีเมลในไฟล์ (เช่น รุ่นที่ 1) จะถูกสร้างไว้โดยยังไม่มีอีเมล แอดมินเติมอีเมลได้ในส่วนโปรไฟล์ หรือให้เจ้าของกรอกเองตอนเปิดใช้งาน
- แอดมินแก้โปรไฟล์สมาชิกได้ (ชื่อ/อีเมล/เบอร์/รุ่น) สมาชิกแก้ชื่อและเบอร์ของตัวเองได้ที่หน้า "บัญชีของฉัน"
- แนบไฟล์ให้สมาชิกได้ทั้ง PDF / JPG / PNG (ไม่เกิน 4MB) โดยตั้งชื่อไฟล์ที่แสดงเอง

> หมายเหตุ: หลัง merge เข้า main Vercel จะ build และอัปเดตเว็บ Production เองภายใน 2–3 นาที (ดูสถานะที่ Vercel > Deployments)

## รุ่นที่เปิดรับสมัคร + ราคา (หน้าแอดมิน > เนื้อหาเว็บ > รุ่นที่เปิดรับสมัคร)
- เพิ่ม/แก้/ลบรุ่นได้หลายรุ่น (ไฟล์ `content/cohorts/<รหัสรุ่น>.yml`) — ชื่อรุ่น, สถานะ (เปิดรับ/เต็ม/ปิดรับ/ซ่อน), จำนวนที่นั่ง, ราคา 3 แพ็กเกจ, ตารางเรียน (กล่องในการ์ด เลือกไอคอนได้ เลื่อนลำดับได้)
- "คัดลอกเป็นรุ่นใหม่" เริ่มรุ่นถัดไปจากข้อมูลรุ่นเดิม · รหัสรุ่นตั้งครั้งเดียว (ใบสมัครอ้างถึงรหัสนี้) — อย่าลบรุ่นที่มีผู้สมัครแล้ว ให้เปลี่ยนเป็น "ปิดรับสมัคร" แทน
- หน้าแรกแสดงทุกรุ่นที่ไม่ซ่อน, ส่วน "ค่าอบรมหลักสูตร" ใช้ราคาของรุ่นแรกที่เปิดรับ (ถ้าราคาแต่ละรุ่นต่างกัน การ์ดรุ่นจะแสดงราคาของรุ่นนั้นด้วย)
- ฟอร์มสมัครเลือกได้เฉพาะรุ่นที่เปิดรับ ค่าเรียน/QR ใช้ราคาของรุ่นที่สมัคร

## รับสมัครเรียนออนไลน์ (`/apply`)
- ผู้สมัครต้องสมัครสมาชิก/เข้าสู่ระบบก่อน แล้วกรอกฟอร์ม 5 ขั้น: ข้อมูลส่วนตัว → การศึกษาและที่ทำงาน (รวมสัตวแพทย์ผู้ควบคุม) → รุ่นและแพ็กเกจ (ผู้ชำระ: ตนเอง/นายจ้าง) → เอกสาร → ตรวจทานและยินยอม
- เอกสารที่ต้องแนบ: **สำเนาบัตรประชาชน** และ **สำเนาวุฒิการศึกษา (ม.6 ขึ้นไป)** (PDF/รูปภาพ ขนาดเท่าไหร่ก็ได้ ระบบย่อรูปและ PDF ให้อัตโนมัติก่อนส่ง) เก็บในฐานข้อมูล เปิดดูได้เฉพาะเจ้าของและแอดมิน
- แอดมิน `/manage` → แท็บ "ใบสมัคร": เปิดดูข้อมูลและเอกสาร ตั้งสถานะเอกสารรายไฟล์ → ผ่านการตรวจสอบ / ขอแก้ไข (ผู้สมัครแนบใหม่เฉพาะไฟล์ที่ไม่ผ่าน) / ไม่ผ่าน · ส่งออก CSV
- การชำระเงิน 2 ส่วน: ค่าเรียน (ชำระให้ Dr.John) และค่าตรวจสอบคุณสมบัติ (ชำระให้สัตวแพทยสภา) — ตอนนี้แสดงเป็นขั้นตอนในหน้าสถานะ ระบบรับชำระค่าเรียนจะเพิ่มภายหลัง

## ชำระค่าเรียนด้วยพร้อมเพย์ + ตรวจสลิปอัตโนมัติ
หลังแอดมินกด "ผ่านการตรวจสอบ" ผู้สมัครเห็น QR พร้อมเพย์ (มียอดเงินในตัว) ในหน้า `/apply` → โอน → แนบสลิป
- ค่าเริ่มต้นใช้ QR ชำระบิลของ Dr.John Pet Co., Ltd. (SCB 038-485804-4) ใส่ยอดให้อัตโนมัติ ไม่ต้องตั้งอะไร — ถ้าจะเปลี่ยนเป็นพร้อมเพย์ทั่วไป ตั้ง `PROMPTPAY_ID` และ `PROMPTPAY_NAME` บน Vercel
- **ตรวจสลิปอัตโนมัติ (SlipOK):** สมัคร https://slipok.com ผูกบัญชีรับเงินของบริษัท แล้วตั้ง `SLIPOK_BRANCH_ID`, `SLIPOK_API_KEY` ระบบตรวจว่าสลิปจริง ยอดตรง และไม่ถูกใช้ซ้ำ ผ่าน = ยืนยันทันที + อีเมลยืนยัน
- ถ้ายังไม่ตั้ง SlipOK: สลิปเข้าสถานะ "สลิปรอตรวจ" แอดมินได้อีเมลแจ้ง เปิด `/manage` → ใบสมัคร → ดูสลิป → "ยืนยันว่าชำระแล้ว" / "สลิปไม่ผ่าน"
- ค่าตรวจสอบคุณสมบัติชำระให้สัตวแพทยสภาโดยตรง (ระบบแสดงเป็นขั้นตอนเท่านั้น)

## อีเมลแจ้งทุกขั้นตอน
ระบบส่งอีเมลเมื่อ: ส่งใบสมัคร / ส่งแก้ไข / ผ่านการตรวจสอบ (พร้อมลิงก์ชำระ) / ขอแก้ไข (ระบุเอกสารที่ต้องแก้) / ไม่ผ่าน / ชำระสำเร็จ และแจ้งแอดมิน (`ADMIN_EMAILS`) เมื่อมีใบสมัครใหม่ สลิปรอตรวจ และชำระแล้ว
- ผู้สมัครกด "ตอบกลับ" แล้วถึง `MAIL_REPLY_TO` (ค่าเริ่มต้น info@vetvpp.com) / อีเมลแจ้งแอดมินกดตอบกลับถึงผู้สมัครโดยตรง
- ต้องตั้งอีเมลผู้ส่งตามข้อ 4 (Gmail หรือ Resend) — ถ้ายังไม่ตั้ง ระบบไม่ส่งอีเมล (บันทึกใน log แทน) แต่ส่วนอื่นทำงานปกติ
